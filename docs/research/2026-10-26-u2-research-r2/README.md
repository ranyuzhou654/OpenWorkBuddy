# U2 第二次真实研究与文档导出修复

已实现单次正文生成、多格式导出，以及预算收尾和可用工具提示。U2-2 的 Agent 自行生成了 Markdown 并导出 Word；**交付后的第 9 次模型请求发生 APITimeoutError，整次运行仍记 error，不能计为完整成功**。原始 Word 有跨页排版问题，另用修复后的排版器离线导出，未改正文。

可审阅的交付物：[Markdown](research-brief.md)、[排版修正版 Word](assisted/research-brief.docx)。后者属于 Codex 辅助导出，4 页均已渲染、逐页检查；两份 Word 的可见文字均与 Markdown 相等。独立人工验收尚未完成。

## 产品变化

- `export_document(source, path)` 把本会话已交付且未改变的 Markdown 转为 Word/PDF；无需重新发送正文，不追加第二遍文献表，保留原引用状态、快照及源文件 hash/版本。重启后仍能导出；独立检查源文件读取权限和目标写入权限，拒绝覆盖用户修改。
- 请求数或墙钟剩余不足四分之一时进入收尾，阈值分别最多 3 次请求、45 秒；显示剩余额度，禁止新增网页搜索/抓取，继续允许已授权的本地交付。总次数和截止时间不重置。**本次真实运行未触发收尾阈值，这项行为目前由本地回归覆盖。**
- 未知工具错误列出当前声明的可用工具；系统提示要求只调用已提供的工具。
- 试跑后发现表格行被拆断、末尾说明形成孤页；排版器增加按内容分配列宽、禁止拆行、跨页重复表头，正文保持 11pt 并调整段后距。修订后离线重导，未追加收费试跑。
