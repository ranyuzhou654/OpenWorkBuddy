## 实际修复

1. **当前记忆被旧对话覆盖。** 请求中的 system 已更新为 `preferred_locale=ja-JP`，模型却根据旧的用户请求、memory 工具回执及旧文件继续写 `zh-CN`。仅补 system 优先级声明的第二次试跑仍复现。现在将最新 `context_state` 投影为其实际位置上的 host 通知，明确旧回执是历史值；只投影最新一次，原始消息不改写。摘要隐藏该事件时，在摘要之后恢复一次通知。system 仍保存当前上下文；该通知增加一份当前保存内容，纳入现有 token 估算和压缩检查。
2. **权限说明与实际规则不一致。** 原说明只描述 workspace 预设，未展示配置覆盖规则，模型尝试了已经 deny 的 bash。现在同时展示配置和会话覆盖规则、匹配顺序与固定审批约束，执行仍走原 gate。新增拒绝命令不产生文件的回归。评测自身也修正了只允许 `{root}/*` 却遗漏目录 `{root}` 的规则，使 glob 可用。

第三次真实试跑验证了通知在会话重建后的效果。随后增加“事件被摘要隐藏时恢复通知”，由最新本地检查覆盖，未再次调用模型。
