# R-C：文档证据与试用体验

2026-10-26，按二轮复审第 6.5、6.6 节与 R-C 阶段实施。本阶段只进行了本地实现、合成资料回归及本地模拟模型的浏览器测试，真实模型请求、搜索服务调用、办公外发均为 0。

## 来源与导出

- 来源分别记录 discovered、fetched、extracted、inspected。二进制下载不会通过“片段进入上下文”检查；提取和上下文读取也不表示事实正确。
- 保存 URI、会话可见范围、访问时间、内容 hash、原始/提取文本快照。网页记录字符范围，文件记录页/行范围；实际请求投影后才追加 evidence，保留可见片段 hash。spill 记录首尾范围；prune 路径指针不会冒充正文已读，继续读取 spill 则仍关联原来源版本。
- 同 URI 不同内容产生不同编号；第一次发现可以升级到第一次获取。交付物另外冻结当时的来源记录，随后重新搜索、抓取或切分支不能替换旧报告的依据。
- create_document 的 Markdown、Word、PDF 自动附参考文献：标题、URI、访问时间、hash、定位及状态。Word/PDF 通过关系/注释检查确认存在可点击链接。文档解析使用被 hash 的同一份字节，避免原路径变化污染缓存。
- 文件卡片分开显示结构、引用、数字与计算、人工版式与事实验收。后两项默认未评估；任务 changed 只承认本轮可验证产物/回执，不能推导事实或人工验收通过。present 只读交付已有文件，不会替它改写参考文献。

## 检索与索引

仍用 SQLite FTS5，无向量库。查询契约包含授权 session 集合、project_id、session_id、access_scope；模型不能通过工具参数自行扩大范围。普通会话默认当前项目，无项目会话默认本会话；顶部选择跨项目是用户明确启用，API 也支持选择会话列表。全局搜索页独立选范围；项目菜单可排除索引。

recall 返回稳定的 rec_ 标识，read_record 按字符范围读取索引上下文，每次最多 12,000 字符。每次查询重新取当前范围，排除或删除后旧命中也不可继续读。

合并队列最多 128 个会话；单个后台解析任务按每会话每批最多 256 条完整 JSONL 行推进字节游标。启动/运行边界和后台轮询更新缓存，recall 本身不扫描日志。附件/来源文本最多索引前 60,000 字符；失败事务 rollback，坏附件仍索引文件名，其他会话继续推进。缓存可能落后更新周期，未做大规模吞吐或延迟验收。

## 预算与诊断

默认每次运行 60 次逻辑模型请求、200 次工具尝试、900 秒墙钟时间；当前服务进程同时最多 2 个后台任务。全局默认可在 config.toml 的 [budget] 中改 model_calls/tool_calls/wall_seconds/background_concurrency。会话“诊断与预算”可覆盖前三项，下次新运行生效；同一运行恢复沿用冻结上限。

摘要和失败模型请求计入同一模型计数，工具批次在任何副作用开始前预留额度；预算触顶返回 limit，不追加收费总结。重启不清零已记录调用，旧版本的 tool_started 也计入基线。旧版本没有记录的失败请求不能补造，SDK 内部 HTTP 重试也不冒充逻辑调用计数。

墙钟从原始 run.started_at 计算，包含审批等待和重启停机；触顶取消执行协程。同步解析线程必须收尾后才能释放维护锁，不提供操作系统级的硬杀解析保证。后台并发配额以当前服务进程为范围，独立服务/CLI 没有共享配额。

诊断包含运行状态、冻结上限、调用/工具数量、失败类型、request ID、工具错误位置、token、未知响应及索引错误；不返回用户提示或密钥。没有核对套餐账单/价格表，费用保持 unknown，未实现货币或 token 硬上限。
