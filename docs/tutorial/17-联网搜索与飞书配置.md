# 联网搜索与飞书配置

本页用于给已启动的本机 OpenWorkBuddy 配置网页搜索，以及本人可访问的飞书文档和日历读取。

## Tavily

1. 打开设置 → 联网搜索，在 Tavily 控制台获取 API Key。
2. 在密码输入框粘贴密钥，点击“保存密钥”。输入框会清空，页面只显示末 4 位。
3. 保存本身不请求 Tavily。需要验证时，点击“测试搜索（1 次请求）”；它使用已保存的密钥执行一次真实查询。输入新值但未保存时，测试按钮不可用。

Tavily 与模型密钥复用同一个 SecretStore：默认写入 ~/.nwb/secrets.json，文件权限 0600，config.toml 只保存 secret:search 引用。读取设置的 API 不返回明文，前端不将密钥写入浏览器存储。后续填写或替换搜索密钥不会改动已有模型连接。

搜索可用后，当前研究题为：如何用 OpenWorkBuddy 每周生成一份可追溯的 AI 技术周报，并在有实质变化时更新。结果应给出 3–5 个实际读取的官方来源、方案比较、一周内改动清单和验收条件；获取日期和发布日期分开记录。

## 飞书

飞书使用官方 lark-cli 的本人身份授权，不在网页中收集 App Secret 或访问令牌。

先检查安装与当前身份：

```sh
lark-cli --version
lark-cli auth status --json --verify
```

bot 可用不等于本人已经登录。需要以 user 身份读取个人文档和日历。若本机已有应用配置，可以直接授权；只有首次使用且尚未配置应用时才运行 lark-cli config init --new，并按提示在飞书完成应用配置。

在你自己的终端进行首次只读授权：

```sh
lark-cli auth login --scope "docx:document:readonly calendar:calendar:readonly"
```

按终端给出的链接或二维码确认权限。若提示应用尚未开通相应权限，需要应用管理员先开通，再重新授权。额外业务权限按实际缺失项追加，不直接申请所有业务域。

完成后，回到设置 → 连接器，点击“重新检查”。确认页面显示本人账户，再勾选“启用”。在对话里提供允许读取的具体文档链接或日历名称，助手才能知道本次业务范围。

如果由 Codex 帮你发起登录，它会给出本次授权链接和二维码。完成后回来说明“已授权”，由 Codex 领取并验证登录结果；不需要在聊天里发令牌。

只读授权不包含发布权限。后续发布试验另行指定测试文档或测试群，并在应用中核对逐次审批内容。未完成的配置或试验不能标为通过。
